# DS娘 build6 真机测试说明

版本标识：`0.4.0-beta.6`；IPA 实际 iOS plist：`0.4.0 (0.4.0.6)`；产物为无签名 IPA。

## 安装前

使用 Sideloadly、AltStore 或开发者证书重签安装。建议先保留 build5，再安装 build6；若两包使用相同 bundle identifier，覆盖安装前先备份 App“文件”目录中的数据。

## 冒烟测试

1. 首次启动能进入主界面，头像、背景、角色立绘均不是空白。
2. 发一条普通消息，能收到带合法情绪标签的回复；重启后继续对话。
3. “高级设置 → DS娘 → Persona Engine”可看到动态状态和检索式记忆两个开关；默认分别为开、关。
4. 复制 Persona 配置 JSON，确认 release 为 `0.4.0-beta.6`。
5. 创建一个两分钟后的待办提醒，把 App 切到后台，确认通知到达。
6. 触发一次联网搜索/工具调用，确认结果进入最终回复而不是停在“调用工具”。
7. 开启飞行模式发送消息，确认失败可理解、恢复网络后可继续。

## 重点回归

- 连续 20 轮：称呼、关系边界、语气和情绪标签不漂移。
- 重启两次：动态状态与记忆仍能延续，没有重复待办。
- 同一账号两设备或清空/恢复数据时：云同步不复制笔记、待办和日志。
- iPad：横竖屏、设置页和输入框无裁切。

## A/B 选测

只有在记录对照样本时才开启“检索式记忆”。同一组提示分别以关闭/开启运行，记录末行问句、主动建议、重复追问和错误回忆；测试后恢复关闭。
